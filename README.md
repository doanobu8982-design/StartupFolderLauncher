# 高機能スタートアップランチャー (StartupFolderLauncher)

[English Documentation (README.en.md)](README.en.md)

Windows標準のスタートアップフォルダの利便性を維持しながら、管理者権限（UACダイアログのスキップ）での起動、自由な起動順序の並び替え、エクスプローラー（タスクバー）準備完了待機、完全不可視ネイティブ実行ファイル（`launcher.exe`）による**完全黒窓ゼロ化**、および画面ロック解除時の自動死活監視・復帰を実現するポータブルランチャーです。

フォルダを一本化し、管理者権限の切り替えや起動順序の並び替えもすべて直感的なGUIからワンクリックで完結します。

---

## 1. 特徴とアーキテクチャ

* **完全黒窓ゼロ化（`launcher.exe`）**:
  * Windows標準のC#コンパイラ（`csc.exe`）でビルドされた極小ネイティブGUI実行ファイル `launcher.exe` を採用。
  * 従来の `powershell.exe -WindowStyle Hidden` につきものだった「0.05秒の一瞬の黒窓（コンソール）点滅」すら一切発生せず、完全不可視でサイレントに実行されます。
* **フォルダの完全一本化とGUI権限切り替え**:
  * アプリケーションはすべて単一の `スタートアップ/` フォルダに配置します。
  * 管理画面の一覧にある「管理者」チェックボックスをONにするだけで、該当アプリを最上位特権（UAC確認プロンプト完全スキップ）で起動可能。OFFの場合はエクスプローラーのCOMインターフェース（`Shell.Application`）経由で安全に通常権限で起動します。
* **GUIによる起動順序の自由な並び替え**:
  * 管理画面の「▲ 上へ」「▼ 下へ」ボタンで起動順序を自由に変更可能。設定順序に従って順番にアプリが起動します。
* **ウィンドウサイズの自動記憶・復元**:
  * 管理画面を閉じた際のウィンドウサイズ（幅・高さ）を自動保存し、次回起動時にその大きさで復元します。
* **描画ちらつき根絶＆リアルタイム差分ログ自動追記**:
  * 管理画面一覧（DataGridView）のダブルバッファリング強制有効化と描画ロック（`SuspendLayout` / `ResumeLayout`）により、更新時の点滅ループを完全根絶。
  * 2秒周期の安全なタイマーにより、新規出力されたログのみをテキストボックスへ差分追記（`AppendText`）・自動スクロールするため、画面全体の再描画を起こさずスムーズに最新状況を把握できます。
* **ダブルクリック自動昇格**:
  * `インストール.bat` および `アンインストール.bat` はダブルクリックするだけで自動的にUAC（管理者昇格）プロンプトを要求し、安全に実行。
* **シェル起動待機（ログオン時）**:
  * ログオン直後、タスクバー（`Shell_TrayWnd`）の描画完了を Win32 API 経由で監視・待機してからアプリ群を順次起動し、タスクトレイ登録の失敗や描画崩れを防止。
* **安全設計：死活監視は「デフォルトOFF」**:
  * 画面ロック解除時（SessionUnlock）のプロセス死活監視＆自動復帰は、**明示的に「監視ON」に設定したアプリのみを対象**とします。
  * 設定されていないアプリはロック解除時に起動処理を行わず安全にスキップされるため、意図しない多重起動事故を根絶できます。
* **GUIからワンクリックで監視設定＆プロセスピッカー**:
  * 管理画面（GUI）のチェックボックスで監視のON/OFFを即座に切り替え可能。
  * 「監視プロセス変更」ボタンから、実行中プロセス一覧を参照してマウス操作だけで監視対象プロセス名を登録できます（JSONの手作業編集は不要）。
* **排他制御（Mutex）**:
  * 名前付きミューテックス（`Global\StartupFolderLauncher_Mutex`）により、短時間の多重イベント発生時でも1プロセスのみが安全に実行されるよう排他制御。
* **日本語パス・全角記号への完全対応**:
  * PowerShellスクリプト全域で `-LiteralPath` を徹底し、全角括弧（`（` `）`）やスペースを含むパスでも誤作動を起こさない堅牢な設計。
* **詳細ログ記録と自動ローテーション**:
  * 1行1エントリ形式（BOMなし UTF-8）でログを追記。設定行数を超えた場合は自動的に最新ログのみへ切り詰め。

## 2. ディレクトリ・ファイル構成

```text

├── スタートアップ/             # 起動したいすべてのショートカットや実行可能ファイルを配置
│   └── .gitkeep

├── config.default.json         # 設定ひな形テンプレート（Git管理対象）

├── launcher.ps1                # ランチャー処理本体（バックグラウンド動作用）
├── view_status.ps1             # 管理画面GUIスクリプト（Windows Forms）
├── scripts/                    # 内部処理用スクリプト配置フォルダ
│   ├── build_package.ps1       # 配布用クリーンポータブルZIP生成スクリプト
│   ├── launcher.cs             # launcher.exe ソースコード
│   ├── register_task.ps1       # タスクスケジューラ登録処理本体
│   └── unregister_task.ps1     # タスクスケジューラ削除処理本体
├── launcher.log                # 実行ログ（初回実行時に自動生成）
├── README.md                   # 日本語ドキュメント
└── README.en.md                # 英語ドキュメント
```

## 3. セットアップ手順

### 3.1 タスクスケジューラへの登録
1. 本フォルダを任意の恒久的な場所（例: `C:\Tools\sutaatoappu` など）に配置します。
2. `インストール.bat` を**通常のダブルクリック**で実行します。
3. 自動的にUAC（管理者昇格）プロンプトが表示されるので「はい」を許可します。
4. 以下の2つのタスクがタスクスケジューラに自動登録されます（最上位特権・黒窓ゼロ）:
   * **`StartupFolderLauncher`**:
     * **トリガー**: ユーザーログオン時 (`LogonTrigger`)
     * **実行内容**: `launcher.exe` （引数なし）
   * **`StartupFolderLauncher_Unlock`**:
     * **トリガー**: 画面ロック解除時 (`SessionStateChangeTrigger` - SessionUnlock)
     * **実行内容**: `launcher.exe -IsUnlockTrigger`

### 3.2 登録の解除
1. `アンインストール.bat` をダブルクリックして実行します（自動的にUAC昇格されます）。
2. タスクスケジューラから登録タスクがすべて一括削除されます。

## 4. 使い方

### 4.1 アプリケーションの登録
* `スタートアップ` フォルダに、起動したいアプリケーションのショートカット（`.lnk`）または実行ファイル（`.exe`, `.bat`, `.cmd`）を配置します。
* 管理者権限で起動したい場合は、管理画面（`管理画面を開く.exe`）の「管理者」列のチェックボックスをONにしてください。

### 4.2 死活監視の動作仕様
* **ログオン時（PC起動・サインイン時）**:
  * 登録されているすべてのアプリを設定された順序（`launch_order`）に従って起動します（すでに稼働している場合は二重起動防止でスキップ）。
* **画面ロック解除時**:
  * **「監視」が有効（ON）のアプリのみ** をチェックし、プロセスが落ちていた場合に自動再起動します。
  * 監視が無効（OFF）のアプリは何もせず安全にスキップされます（ログに `[Skip] 監視設定が無効(OFF)のためスキップしました` と記録）。

### 4.3 設定ファイル (`config.json`) の仕様

管理画面（GUI）から操作した場合、本ファイルは自動的に更新・保存されます。

```json
{
  "settings": {
    "stagger_interval_ms": 500,
    "logon_check_shell": true,
    "shell_timeout_sec": 30,
    "max_log_lines": 200,
    "window_width": 1040,
    "window_height": 680,
    "launch_order": [
      "常用マクロ.ahk.lnk",
      "PowerToys (Preview).lnk",
      "MSI Afterburner.lnk"
    ]
  },
  "overrides": [
    {
      "match_name": "LINE.lnk",
      "enabled_watch": true,
      "run_as_admin": false,
      "watch_process_name": "LINE",
      "arguments": "",
      "hidden": false
    }
  ]
}
```

#### 基本設定 (`settings`)
| 項目名 | 型 | デフォルト値 | 説明 |
| :--- | :--- | :--- | :--- |
| `stagger_interval_ms` | 数値 | `500` | アプリケーション起動ごとの待機時間（ミリ秒）。急激なCPU負荷を緩和します。 |
| `logon_check_shell` | 真偽値 | `true` | ログオン時にタスクバー（エクスプローラー）の準備完了を待つかどうか。 |
| `shell_timeout_sec` | 数値 | `30` | タスクバー待機の最大タイムアウト（秒）。 |
| `max_log_lines` | 数値 | `200` | `launcher.log` の最大保持行数（超えた場合は古い行を削除）。 |
| `window_width` | 数値 | `900` | 管理画面ウィンドウの保存幅（ピクセル、最小860）。 |
| `window_height` | 数値 | `550` | 管理画面ウィンドウの保存高さ（ピクセル、最小500）。 |
| `launch_order` | 配列 | `[]` | 起動順序を定義する完全ファイル名の配列。 |

#### 個別オーバーライド定義 (`overrides`)
| 項目名 | 説明 |
| :--- | :--- |
| `match_name` | ファイル名のワイルドカード照合パターン（例: `LINE.lnk`, `Discord*`）。 |
| `enabled_watch` | `true` の場合のみ、画面ロック解除時にプロセス死活監視＆自動復帰を実行。省略時は `false`（監視しない）。 |
| `run_as_admin` | `true` の場合、UACをスキップして管理者権限で直接起動。`false` または未指定の場合は通常権限（Shell経由）で起動。 |
| `watch_process_name` | 死活監視対象とするプロセス名（拡張子 `.exe` を除く）。ランチャーやアップデータ経由で別プロセス名になる場合に指定。省略時はターゲット実体の拡張子なしファイル名。 |
| `arguments` | アプリケーションに渡す追加コマンドライン引数。 |
| `hidden` | `true` の場合、ウィンドウを非表示（バックグラウンド）で起動。 |

## 5. ステータス管理GUIの使い方

`管理画面を開く.exe` をダブルクリックすることで、黒窓（コンソール）を一切表示させずに直接GUI管理画面を起動できます。

* **登録アプリ一覧**:
  * **「順序」列**: 起動順序（1, 2, 3...）を表示。
  * **「監視」チェックボックス**: チェックを入れると監視ON、外すと監視OFFになり、`config.json` に即時自動保存されます。
  * **「管理者」チェックボックス**: チェックを入れると管理者権限（UACスキップ）起動、外すと通常権限起動になり、即時自動保存されます。
  * アイテム名（.lnk非表示）、現在の稼働状況（🟢 稼働中 / ⚪ 停止中）、監視対象プロセス名、実体パスを一目で確認できます。
* **「▲ 上へ」「▼ 下へ」ボタン**:
  * 選択した行の起動順序を上下に入れ替え可能。変更内容は即座に `config.json` の `launch_order` に保存されます。
* **「監視プロセス変更」ボタン**:
  * アプリの行を選択してこのボタンを押すと、モーダルダイアログが開きます。
  * **現在実行中のプロセス一覧** が自動取得・表示されるため、リストから目的のプロセスをクリックして「保存」を押すだけで、正確なプロセス名が登録され、監視がONになります。
* **最新実行ログ**:
  * 直近の動作ログを表示し、2秒周期の安全なタイマーにより新規ログをリアルタイムで自動追記・自動スクロールします。
* **クイックアクション**:
  * `[再読み込み]`: 一覧とログの最新状態を再取得。
  * `[スタートアップを開く]`: `スタートアップ` フォルダをエクスプローラーで開く。
  * `[▲ 上へ]`: 選択中アプリの起動順序を1つ繰り上げる。
  * `[▼ 下へ]`: 選択中アプリの起動順序を1つ繰り下げる。
  * `[監視プロセス変更]`: 実行中プロセス一覧から監視対象を選択。
  * `[スタートアップ実行]`: `launcher.exe` を完全不可視でバックグラウンド実行し、スタートアップ処理を今すぐ実行。

## 6. ログ仕様

ログファイル（`launcher.log`）はUTF-8（BOMなし）で出力されます。

### ログフォーマット
```
[YYYY-MM-DD hh:mm:ss] [イベント] [権限] [結果] 対象名: メッセージ
```

* **イベント**:
  * `Logon`: PCへのサインイン・ログオン時
  * `Unlock`: 画面ロック解除時
  * `Manual`: GUIや手動実行時
  * `DryRun`: テスト・シミュレーション実行時
* **権限**:
  * `Normal`: 通常ユーザー権限
  * `Admin`: 管理者特権
* **結果**:
  * `OK`: 起動成功 / シミュレーション成功
  * `Skip`: 既に起動中、監視OFF、または多重実行防止によるスキップ
  * `Restart`: 再起動実施
  * `Warn`: タイムアウトや設定構文エラー（フォールバック処理継続）
  * `Error`: リンク切れ、実体ファイル不在、起動例外

## 7. トラブルシューティング

1. **画面ロック解除時にアプリが自動起動（復帰）しない**:
   * 管理画面（`管理画面を開く.exe`）を開き、対象アプリの「監視」列にチェックが入っているか確認してください。デフォルトでは安全のため監視はOFFになっています。
2. **常駐しているのに毎回二重起動してしまう**:
   * ショートカット名やファイル名が常駐プロセス名と異なる場合があります（例: アップデータ経由で別名プロセスが起動する場合など）。管理画面で対象アプリを選択し、「監視プロセス変更」ボタンから正しい実行中プロセスを選択して保存してください。
3. **管理者権限で動かしたいのにUACダイアログが出る**:
   * 管理画面の「管理者」列のチェックボックスをONにしてください。本ランチャーの管理者起動タスク経由でUACなしで直接起動されます。
4. **タスクを最新の launcher.exe 構成に更新したい**:
   * `インストール.bat` をダブルクリックして再実行してください。タスクスケジューラの登録が `launcher.exe`（完全黒窓ゼロ）構成に上書き更新されます。
5. **ショートカットを置いたのに起動しない**:
   * `launcher.log` または管理画面のログを確認してください。実体パスが存在しない場合は `[Error] 実体ファイルが存在しません` と記録されます。
